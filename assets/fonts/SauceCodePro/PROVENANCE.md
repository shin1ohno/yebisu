# SauceCodePro Nerd Font Mono

Unmodified font binaries from Nerd Fonts v3.5.1, SourceCodePro.zip:
https://github.com/ryanoasis/nerd-fonts/releases/tag/v3.5.1

Archive SHA-256: `e0000bc77cd77279840d8613e98727548f81f291a571be0be8699c8e3be36fd3`.

The Mono variant keeps terminal icons within one cell. Regular, Bold, Italic,
and BoldItalic are included. The app uses these fonts only within its process.
See LICENSE.txt and NERD-FONTS-LICENSE.txt for licenses and README.md for
upstream credits. License text whitespace and line endings are normalized.
