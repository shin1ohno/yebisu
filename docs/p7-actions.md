# P7 action contract

`actions::catalog` is the one action table consumed by the keyboard matcher, action toolbar and palette. Each row contains `sheprd_commands::CommandInfo`, its display label, the dependency's default shortcuts and current availability. Display messages are the P7 subset of the fork's English Fluent catalog at 398c132a0, recorded in PROVENANCE.tsv; numbered labels substitute the catalog's number. `sheprd-commands` is the only new dependency, pinned to the existing fork revision, for command identities, default shortcuts and typed API requests. No dependency version upgrades are intended.

Allowed commands are new tab, split right/down, next/previous tab or pane, directional pane focus, zoom, close pane/tab, tab positions 1–9, toggle board and command palette. Desktop/chat actions are not registered. Availability requires a live, unsuspended host, a catalog request for the current snapshot, the advertised method, no daemon popup and no pending command. Local board/palette actions remain available. The tab strip addresses IDs, not numbers, and checks host, generation, boot and workspace again when tapped.

A request is queued while holding the reader mailbox lock, so its response cannot race registration of the correlation ID. Before releasing the lock, the view installs a command barrier and detaches held keys, queued input and composition. Command barriers only finish on their correlated reply/rejection or disconnect, never on an unrelated or newer focus snapshot. While waiting, additional API focus and resize are refused/deferred and input is discarded, not replayed. The next paint sends the current geometry after the reply. The library's existing FIFO writer and boot fencing remain in place.

P7 handles key events and API dispatch. P12 owns `set_menus`, native menus and the Command-hold overlay. No terminal control sequence is generated for an app action. Unmatched chords, Control prefix keys, composition and daemon popups bypass the shortcut matcher. Repeated shortcut keydown cannot repeat app commands; matching keyup is consumed without fabricating a terminal release. See variants.md for Command-as-Control precedence.

Checks use a gated private wire peer: create/split receipt arrives before the gate releases its reply; focus, tab selection, resize, input and composition are exercised in that interval. Additional checks cover stale host/boot/generation/tab, unavailable slots, catalog availability, prefix/modifier passthrough, real GPUI key-event adapter, unrelated response and rejection. `scripts/ios/p7-check.py` checks received API requests and rendered tab/pane counts plus the input destination in order, with negative oracle controls in `test_p7_check.py`.
