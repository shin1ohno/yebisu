## Remaining dependency and runtime gates

Herdr2 `CoreTerminal::input` calls `Attachment::write`, which queues chunks into the pinned SDK transport. The consumer epoch cancels commands before its worker dispatch check only. A modal open after that check, or after the SDK has accepted bytes, is not cancelled by this source change. Do not certify full F19. The separately owned SDK proposal must supply a final-writer cancellation/barrier or a precise in-flight admission contract; no SDK source or pin change is included here.

The H1 async fixture yields after UI stamp validation. On release it still runs the live target check and actual SDK publication. Modal-only cancellation leaves the live target unchanged, so the receiving barrier checks cancellation propagation rather than only a stale-target refusal. A test-only OS-thread pause is used for the separate core worker queue case. Neither seam exists in production builds.

Every Simulator QA/observation mode requires current Owner provider provenance before read/copy/confirm. Startup/view/operation receipts contain tags and booleans only. Disabled/full/disconnected observation admission refuses operations. Runtime preflight requires the emitted receipt and displayed `QA injected key provider` before a key probe; synthetic fixture success never substitutes for that runtime observation.

## F24 native collection contract

Use `python3 scripts/ios/p11-privacy-check.py MANIFEST.json` after a controller-leased run. Manifest schema=1 includes exact head, run_id, collection_directory and sinks mapping roles to actual path+sha256. Required roles: observation JSONL, diagnostics JSONL, native_stderr, runner_stdout. Collect rotated diagnostics and all other .log/.jsonl files under the collection directory as additional roles. Missing, empty, digest-mismatched or omitted sinks fail closed. The scanner checks actual provider, diagnostic startup, native stderr and runner positive controls, plus literal and encoded fake-public/private sentinels. It does not manufacture native capture or accept an empty glob. Existing `scripts/ios/sim.sh --out` collects actual OS stdout/stderr; a subsequent XCTest relaunch needs its own native capture, not reuse of the first launch files. Native aggregate collection remains a runner gate until every launch is captured.

No worker real key read/replace/copy, host-trust edit, signing or device operation is authorized. Unknown/one-worker/termination-plus-explicit-reconcile remain unchanged.
